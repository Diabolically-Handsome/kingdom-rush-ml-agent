# 王国保卫战机器学习智能体（Kingdom Rush ML Agent）

**一个从新存档开始、在普通难度下完整打通原版《王国保卫战》（2011）主线全部 12 关的机器学习智能体。**
2026-10-06 在 5 个预留的最终种子上一次性正式评测：**5 个战役全部完整通关**。

据我们检索（2026-10-06：GitHub、arXiv / ACM / Semantic Scholar、YouTube、B 站），这是**第一个有公开记录、
完整打通原版主线战役的机器学习智能体**。先前的相关工作见下文[先前工作](#先前工作)；如果您知道更早的
完整通关记录，欢迎提 issue，我们会更正这一说法。

**精英关（2026-10-07）**：在第二次一次性最终评测中（从新存档打全部 26 关：主线后接 14 个精英关），智能体共通关
79/130 关；5 个种子中有 2 个通关 21 关，各含 9 个精英关；另有 2 个种子在主线第 11 关失败（主线部分与上次完全相同），
即在这 5 个新种子上主线通关 3/5（[详情](#精英关2026-10-07)）。

## 自己验证（不需要游戏）

```bash
python verify_evidence.py
```

会检查所有哈希链日志；核对一次性最终作业冻结时用的正是公开的代码和配置；从每一局的记录重新算出 5/5；并确认
最终种子没有出现在任何其他运行里；对精英关的最终评测做同样的检查，并核对它的重新执行与策略重放记录。最后一行应为
`ALL CHECKS PASSED`。

## 智能体的构成

* **8B 策略脑**（Ministral-3-8B-Instruct，4-bit，**未微调**）：每关开打前从“计划组合”中选一个作战计划（英雄、
  建造顺序、法术时机、叫波方式等），并选择星星分配方案（升级界面可以免费重置）。所有选择都是对合法选项打分，
  并按所有循环顺序打分取平均（原始模型几乎总选 B）。
* **小网络操作脑**（128×64 的 MLP，行为克隆 + DAgger）：在每个决策点对全部合法动作打分并执行计划——建塔、
  升级、技能、法术（带落点）、日光塔瞄准、叫波、点击（给倒地的首领最后一击、点碎塔上的冰）、等待。
* **计划来源**：只在 10 个训练种子上用进化搜索（稳态遗传算法，22 轮共 20,794 局）得到，困难关卡按多个种子的
  平均成绩评分并在其他种子上验证；每关按“覆盖不同种子”挑选重试用的计划组合。
* **真实游戏**：Steam 版的 LÖVE/LuaJIT 引擎隔离副本 + RPC 宿主；动作都走游戏自己的路径（和界面按钮一样），
  不改金币、血量或波次；无头运行、随机数确定化，每一局都能精确复现。
* **规则**：新存档；星星按游戏规则（剩余生命）获得、按升级界面规则花费；英雄按解锁情况；普通难度；不修改游戏。

## 主要发现

1. **第 9 关需要点击**：首领 J.T. 被打倒后要点他一下才会死；他的冰冻要点 3 次才碎，否则塔一直冻到关卡结束。
   没有点击动作时第 9 关不可能赢（4,613 局搜索 0 胜，最接近的几局首领停在 4 血直到时间上限）；加上之后验证
   72/72 全胜。
2. **星星可以重新分配**：升级界面能免费重置，每个计划带上它测试时用的星星分配（例如打 J.T. 时火雨优先）。
3. **单种子搜索会过拟合**：困难关卡改为 3–5 个种子平均评分、并按种子覆盖挑选重试计划后，彩排通关率从 5/10
   升到 9/10。
4. **大模型的选项字母偏好**：8B 不管内容几乎总选 B；对所有选项顺序取平均后恢复正常。
5. **日志 bug**：整数键与其 JSON 字符串形式在 10 个以上时排序不同，使第一次彩排中止；公开的验证脚本会按修复前
   的规则核对那一条记录。

完整开发日志见 [`docs/DEV-LOG.zh-CN.md`](docs/DEV-LOG.zh-CN.md)。

## 局限

* 每局的随机种子固定（确定性引擎）；一个计划输了就换计划重试。
* 计划是按关卡事先准备的，智能体不会在关内临场改变整体打法。
* 不是端到端的强化学习策略：计划来自进化搜索，操作脑来自模仿学习，8B 是零样本使用。
* 观察来自游戏内部状态（通过 RPC 宿主），不是屏幕像素。
* 精英关：最终评测中第 13、20、21、22、26 关没有拿下；主线第 11 关是整个战役最薄弱的一环。英雄/钢铁挑战只作为
  升级星的来源，并没有全部打赢。
* 只做普通难度；只用 6 个免费英雄。

## 复现

需要您自己拥有《王国保卫战》（Steam，Windows）、Python 3.12，以及 Lumi_Nox 的桥接文件：

```bash
git clone https://github.com/MIO-456/Lumi_Nox Lumi_Nox
git -C Lumi_Nox checkout 77f973431c49f5ab72d3b2501c0e89286997ec46
python -m alpharush_rl.engine --prepare        # 从您的游戏安装构建隔离引擎副本
python tools/campaign-survey.py --check-only --job native-campaign
```

本仓库不包含任何游戏文件。策略脑需要在本地提供 8B 模型服务（`tools/model-worker.py --model 8b --serve`，约 10 GB 显存）。
