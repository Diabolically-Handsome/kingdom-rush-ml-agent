# 第一关：24B 真实结局奖励训练

您已授权现在开始第一关训练，先使用 RTX 5090 上的 Mistral Small 24B。本阶段使用独立 KR1 文本 LoRA，底座 NF4 / BF16；不加载另一个项目适配器。第一轮限定一次实际优化器更新，全部结果和失败均保存，完成后停止，不自动搜索学习率或重复试验。

## 奖励

| 原生结果 | 奖励 |
|---|---:|
| 第一关 Normal 通关 | `1 + 剩余生命 / 20` |
| 第一关 Normal 失败 | `-1` |
| 没有真实终局、超时、操作失败、重放不一致 | 拒绝样本 |

初始生命从原生状态核为 20。胜利须剩余 1–20 生命，失败须剩余 0 生命；异常值拒绝调查，不裁剪。金币、击杀数、星数、建塔数量和用时不加分。目标是先通关，再减少漏怪。

实现为 `alpharush_rl/reward_level1.py`，版本契约为 `configs/scoring-level1-terminal-v2.json`。新名字绑定固定权重；旧 v1 奖励与旧训练记录保留。

## 首轮数据与训练

训练 seed1002 / 第一关 / campaign Normal，先按相同规则建两座箭塔，到 tick361 的一个决定点。全部 26 个合法选项分别执行，之后按冻结规则发波与固定帧推进到原生终局。每个选择都在新原生进程照完整命令重放，核全部导出状态摘要、动作回执和终局。它是一个决定点的分支训练，不能当作模型自主整局训练。

策略状态移除 `level_path_wave_counts` 全关未来波次数。完整原始状态另存，用于重放。A1/A2 来自该训练 seed；validation 只用已有第二关无奖励初始状态做分布护栏。第三关留出和其他留出种子不读。

新数据、采集账本、代码冻结、24B 参考分布、更新和候选目录都在 `runtime/rl/level1-24b-phase1/`。首次采集的 Windows Python 启动链工程错误在游戏运行前被隔离门禁拒绝，旧记录保留；唯一 r1 修复核进程在同一个专属 Windows Job Object 中，原失败耗时仍计入 300 秒采集总预算。GPU 阶段最多一个作业、1200 秒、一次参数更新。

训练读取同一个底座、相同完整提示和全部合法字母的独立冻结 π0。使用有限合法动作上的精确 `pi_adv` 和 KL 约束，不使用未来结局作为提示。校准、反传重算、参数实际改变、KL、熵、预期奖励方向、完整含 KL 目标均检查；完整目标不得变差。候选必须同时有外层奖励判定和监督进程接受证书，单独的底层训练 smoke 通过不够。

## 查看与停止

双击根目录 `RL状态.cmd` 查看本轮实际更新步数和结果，详细证据见根目录 `REPORT.md` 与阶段 `latest-training.json`。`tools/train-level1-24b.py` 默认仅读检查；只有显式 `--run` 才使用独立 WSL 环境启动有界训练。当前阶段预算用完后，该入口拒绝再次启动。

在 `runtime/rl/STOP` 或阶段 `state/STOP` 创建停止文件可中止作业；程序不会自动删除停止文件。监督只终止本作业自己的进程。候选不会自动接入游戏，8B 训练状态保持独立。下一阶段需要用新的局面和完整游戏结果核能力，并制定独立预算；本轮训练目标改善不等于整局能力已经提高。
