# As-run scripts (provenance copies)

These are the helper scripts as they were run during the elite-v1 phase (portfolio building, job configuration,
code patches, dry runs and the final's verification). They are kept for provenance: the workspace root is
masked as `C:\Users\<user>\Documents\AlphaRush` and their scratch-directory inputs are not published, so set
the root (and inputs) before re-running any of them. The patches they apply are already in the code tree.
