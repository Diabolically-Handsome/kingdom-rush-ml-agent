# As-run scripts (provenance copies)

The helper scripts as they were run in the elite-v3 phase and its fair re-test: phase setup (`config_elite_v3.py`, its approval text redacted), the v4 / commander code patches (already in the code tree), native probes on a development copy, the S1 / fork / replay job configurations, the offline language-model scoring (`v3_llm_offline.py`), the analyses (the adopted versions are also in `../analysis/`; `v3_regret_eval.py` is the first, superseded evaluation that an adversarial review found confounded), the CUDA initialisation probe, and the phase seal (`config_v3_seal.py`). The workspace root is masked as `C:\Users\<user>\Documents\AlphaRush` and some read their inputs from a local scratch directory (`portfolios_v2_r3.json` is `../../elite-v2/final-artifacts/portfolios.json`).
